# 微信小程序上线审批要求分析

**对象**：创世记 1:1–2 词汇挑战（genesis-vocab-game）
**结论日期**：2026-11-03
**政策依据**：《互联网宗教信息服务管理办法》（国家宗教事务局令第 17 号，2022-03-01 施行）、
微信开放文档「小程序备案」「服务类目」规则、微信开放社区官方答复。

---

## 零、最终决定（2026-11-03 松哥拍板）

**不做小程序版本，维持网页版现状。**

理由：当前主体为个人身份，而宗教类目对个人主体不开放 ——
官方明确「涉及宗教，属个人主体小程序未开放类目，建议申请企业主体小程序」，
且《互联网宗教信息服务管理办法》第六条规定个人不能成为许可申请主体。
在现有主体条件下，小程序路径不成立。

**本文件作为决策依据留档**，若日后注册企业主体可重新评估。
技术侧准备工作已完成并保留（见第五节「音频资源」，23 个 mp3 / 192KB，
任何时候可直接用于小程序开发）。

网页版已上线：https://jacksonyangrs.github.io/genesis-vocab-game/
手机浏览器直接打开即用，已满足小组使用需求。

## 一、结论先行

**有审批要求，且有一条绕不过去的红线：宗教内容。**

这个游戏的内容主体是《创世记》经文（CEV 1:1–2），在微信审核里会被判定为
「涉及宗教」。官方社区的两次明确答复是：

> 你的小程序涉及宗教，属个人主体小程序未开放类目，建议申请企业主体小程序。
> —— 微信社区运营专员，对「我灵赞颂主」小程序（圣经内容）的审核答复

> 若小程序涉及提供宗教相关图片、文字、视频资讯展示解读等服务，则需提供
> 《互联网宗教信息服务许可证》，申请【文娱-宗教信息】类目。

这意味着：**个人主体做这个内容，基本走不通**——宗教类目对个人主体不开放，
而《互联网宗教信息服务许可证》明文规定「个人用户不能成为申请主体」。

有先例可参考：个人主体开发的「圣经工具 lite」（工具类目，含圣经全文检索）、
「今日圣经」（信息查询类目，含圣经全文）曾成功上架，说明**纯检索/工具类**的
宗教内容边界比「讲解/资讯」宽松。但「羔羊读经」「我灵赞颂主」被驳回，
差别在于是否含「解读、评论、资讯式呈现」。

**本次游戏的定位天然站在安全一侧**：这是英语词汇学习工具，释义取自通用词典，
例句是经文原文，**不做经文解读、不做讲道、不做宗教资讯推送**。这是可行的争取空间。

## 二、按主体类型的三条路径

主体资质决定一切，先确定走哪条。

### 路径 A：境内企业主体（最稳）

| 项目 | 要求 |
|---|---|
| 主体资质 | 境内公司营业执照（经营范围覆盖相关业务） |
| 微信认证 | 300 元/年 |
| ICP 备案 | **必须**。周期约 7–20 工作日（平台初审 1–2 天 + 工信部短信核验 + 通管局审核） |
| 宗教类目 | 需《互联网宗教信息服务许可证》，或申请到 `文娱-宗教信息` 类目 |
| 额外 | 域名需 ICP 备案并配置为 request 合法域名；服务器须境内 |

**许可资质是硬门槛。**《办法》第六条规定，申请主体须是「在中华人民共和国境内
依法设立的法人组织或者非法人组织」，且须具备：宗教信息审核人员、互联网宗教
信息服务管理制度、信息安全管理制度、与服务匹配的场所设施资金、近 3 年无犯罪记录承诺书。
第六条明确「境外组织或者个人及其在境内成立的组织不得在境内从事互联网宗教信息服务」。

省以上宗教事务部门审核，20 个工作日内出结果。

### 路径 B：境外主体（松哥当前所在地，周期最短）

| 项目 | 要求 |
|---|---|
| 主体资质 | 境外企业注册证明（香港公司需 BR 商业登记证 + CR 公司注册证）；境外主体**仅支持组织类注册，不开放个人** |
| 微信认证 | 300 元/次 |
| ICP 备案 | **不需**（境外主体免备案、免年审） |
| 宗教类目 | ❌ **基本不可行**——境外主体不得在境内从事互联网宗教信息服务 |
| 服务器 | 必须部署在境外；若部署境内节点会触发备案要求 |

**矛盾点**：境外主体免掉了 ICP 备案（省 7–20 个工作日），但恰恰在宗教这条红线上更窄。
只有当内容被认定为「纯工具/学习应用」而非「宗教信息服务」时才可能过。

审核周期比境内长（7–10 个工作日）。

### 路径 C：个人主体（不可行，仅备案可用）

- 个人主体**无法做微信认证**，也无法申请宗教信息类目
- 官方明确：涉宗教内容「属个人主体小程序未开放类目，建议申请企业主体」
- 个人主体仍需完成小程序备案（备案本身个人可以走通）

**结论**：这个游戏若要上微信小程序，**至少需要企业主体**。

## 三、费用与时间汇总

| 项目 | 境内企业主体 | 境外主体 |
|---|---|---|
| 微信认证 | 300 元/年 | 300 元/次 |
| ICP 备案 | 7–20 工作日（免费） | 免 |
| 宗教信息许可 | 需申请，免费但耗时（20 工作日审批） | 不可行 |
| 服务器 | 需境内（已有 AWS 环境可用） | 需境外 |
| 代码提审 | 1–7 工作日，通常 1–3 天 | 7–10 工作日 |
| **合计** | 费用低，**周期约 4–8 周** | 费用低，周期约 3–5 周（但宗教类目风险高） |

> 若走境内企业主体：认证 + 备案可与开发并行，不必串行等待。
> 宗教许可若确实必须申请，是唯一的长周期项。

## 四、内容定位与审核策略（关键）

审批能否通过，取决于**内容如何呈现**，而不只是有没有经文。已核实的官方口径与先例：

| 行为 | 风险 | 依据 |
|---|---|---|
| 收录经文原文作例句 | 🟡 中 | 「圣经工具 lite」「今日圣经」以此上架（个人主体） |
| 单词释义取通用词典义 | 🟢 低 | 本游戏现状 |
| 音标、词性、例句翻译 | 🟢 低 | 纯语言学习内容 |
| **经文解读、逐节释义、灵修指引** | 🔴 高 | 「羔羊读经」被驳回 |
| **讲经讲道、宗教资讯流** | 🔴 高 | 《办法》第十五、十六条；「恳求再审」案例中被要求补宗教类目 |
| **在线诵经、录音跟读经文** | 🔴 高 | 同上，明确要求补 `文娱-宗教信息服务` 类目 |
| 引导信教、发展教徒 | 🔴 禁止 | 《办法》第十四条明令 |

**本游戏的现有设计恰好避开了所有红线**：
- 释义是词典义（"开始，起初"、"荒芜的，贫瘠的"），不是经文讲解
- 17 个词是英语学习词汇，不是教义概念
- 例句是经文原文，用于语言语境

**⚠️ 但有一个必须调整的点**：现版「发音训练」模式包含**朗读整句经文**的功能
（`sent-*.mp3` 已生成，含 "In the beginning God created the heavens and the earth."）。
「在线诵经」是官方明确点名的驳回理由。**小程序版建议移除整句经文朗读，
只保留单词发音**——单词发音属于语言学习行为，与诵经有本质区别。

另外建议：
- 应用名不出现「圣经」「创世记」等宗教词汇，用「英语生词挑战」「词汇学习」等中性名
- 简介只讲英语学习功能，不提经文学习、查经等表述
- 不设评论区、不做用户内容分享（分享功能也会增加审核风险）

## 五、技术改造清单（小程序版）

小程序运行环境是裁剪过的沙箱，**没有 `speechSynthesis`**。现有网页版的核心能力
必须换实现方式：

| 能力 | 网页版现状 | 小程序版必须改为 |
|---|---|---|
| 单词发音 | Web Speech API `speechSynthesis` | **预生成 mp3** + `wx.createInnerAudioContext()` |
| 整句朗读 | Web Speech API | 预生成 mp3（**建议直接移除**，见上节） |
| 跟读录音 | `MediaRecorder` | `wx.getRecorderManager()` + `wx.createInnerAudioContext()` 回放 |
| 进度存储 | `localStorage` | `wx.setStorageSync` / `wx.getStorageSync` |
| 界面 | HTML/CSS | WXML/WXSS，重写全部视图 |

**音频资源已预先备好**（本次已完成）：
`scripts/gen-audio.sh` 用 macOS 内置 `say` + `ffmpeg` 离线生成，
17 个单词 + 6 条例句共 **23 个 mp3，合计 192KB**，
单个单词约 4KB，完全在包体预算内。无需任何 API key、无需网络。

关键参数：`say -v Samantha -r 175`（美式女声，略慢于默认，单词更清晰）。
音频已抽检：heaven 0.52s / heavens 0.63s、create 0.57s / created 0.65s，
时长区分合理，全部文件解码正常。

## 六、需要松哥拍板的三件事

1. **主体**：走境内企业主体（需营业执照，周期长但宗教类目可行），
   还是境外主体（周期短但宗教类目受限）？是否有可用的公司主体？
2. **内容尺度**：是否接受移除「整句经文朗读」、应用名去宗教化？
   这是过审概率与产品完整性之间的取舍。
3. **是否值得做**：现有网页版已上线可用（手机浏览器直接打开即用），
   小程序版本带来的是「微信内无需跳转」的体验优势，代价是 4–8 周合规周期
   和宗教审核的不确定性。若小组使用场景不强求微信入口，网页版已够。
