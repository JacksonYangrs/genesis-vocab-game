# Genesis Vocabulary Challenge · 创世记 1:1–2 词汇挑战

创世记 1:1–2 (CEV) 生词互动测试游戏，供英语学习小组共同使用。

## 在线使用

https://jacksonyangrs.github.io/genesis-vocab-game/

手机、平板、电脑打开即用，无需注册。每个人的学习进度保存在各自浏览器中，互不影响。

## 练习模式

| 模式 | 说明 |
| --- | --- |
| 英译中 | 看英文单词，选正确的中文意思 |
| 中译英 | 看中文释义，选对应的英文单词 |
| 单词拼写 | 看中文释义，自己拼出英文单词 |
| 听音辨词 | 听发音，选出或拼写对应单词 |
| 混合挑战 | 随机抽题，四种题型综合检验 |

另有**错题复习**（只练答错的词）与**发音训练**（听标准音、逐音节朗读、录音跟读对比）。

## 难度

- **入门** — 4 选 1，干扰项来自其他单词
- **进阶** — 4 选 1 + 部分拼写题，干扰项为易混词（heaven/heavens 等）
- **挑战** — 6 选 1 + 大量拼写题，严格匹配

难度可在首页设置，也可在答题页顶部直接切换（切换后立即重新组卷）。

## 计分

每题 10 分；连续答对从第 3 题起每题额外 +2 分（单题最高 +10）。

## 掌握度

每个词按五级追踪：未练习 → 生疏 → 巩固中 → 熟悉 → 已掌握。
判定依据为最近是否答错、正确率、答题次数与最长连对。掌握情况可在顶部 📊 入口查看。

## 进度备份

进度存在浏览器本地（localStorage）。在「掌握情况」页可**导出 / 导入**进度 JSON，换设备或清理缓存后恢复。组员之间也可以互传进度文件。

## 自定义词库

生词表在 `js/data.js`，每个词包含：

```js
{
  id: 'beginning',
  word: 'beginning',
  phonetic: '/bɪˈɡɪnɪŋ/',
  syllables: ['be', 'gin', 'ning'],
  pos: 'n.',
  meaning: '开始，起初',
  example: 'In the beginning God created the heavens and the earth.',
  exampleZh: '起初，神创造了诸天和大地。',
  tip: '记忆提示',
  note: '易混辨析提示',
  cnDistractors: ['中文干扰项 ×3'],
  enDistractors: ['英文干扰项 ×3']
}
```

`cnDistractors` / `enDistractors` 为人工策划的易混词，是题目质量的关键，修改时请保留易混特征。

## 技术说明

纯静态页面，原生 HTML / CSS / JavaScript，无构建步骤、无第三方依赖。

- 发音使用浏览器 Web Speech API（`speechSynthesis`），无需音频文件
- 跟读录音使用 `MediaRecorder`，需要 HTTPS 或 localhost；不可用时自动降级为「听标准音 + 自评」
- 拼写判定含编辑距离容错：入门/进阶允许差 1 个字母（会提示「接近了」），挑战严格匹配

### 音频资源（`assets/audio/`）

23 个 mp3（17 个单词 + 6 条例句），共 192KB，由 `scripts/gen-audio.sh` 用
macOS 内置 `say` + `ffmpeg` 离线生成，无需任何 API key。

当前网页版**不使用**这些文件（浏览器直接用 Web Speech API 发音）。
预置原因：微信小程序运行环境是裁剪的沙箱，没有 `speechSynthesis`，
若日后做小程序版本，发音必须改为播放预生成音频，届时可直接复用。

重新生成：

```bash
bash scripts/gen-audio.sh
```

## 微信小程序版本（已评估，暂不做）

2026-11-03 评估过小程序上线的审批要求，结论是**在现有主体条件下不可行**：

宗教类目对个人主体不开放，且《互联网宗教信息服务管理办法》第六条规定
个人不能成为许可申请主体。

完整分析（含三条主体路径对比、费用与周期、审核尺度、官方答复与政策链接）见
[`docs/小程序上线审批要求分析.md`](docs/小程序上线审批要求分析.md)。

若日后注册企业主体可重新评估。
